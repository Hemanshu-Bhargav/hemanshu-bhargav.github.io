# Hemanshu Bhargav – Personal Portfolio Website

A clean, responsive personal portfolio site built using HTML, CSS, and JavaScript developed by myself.
This site is hosted on GitHub Pages and serves as a professional landing page to showcase my projects, resume, and contact information.

---

## 🌐 Overview

- **Responsive Design**: Mobile-first layout for all screen sizes.
- **Simple Stack**: Built without frameworks for speed and portability. Astro JS leverages JS without requiring libraries so this website remains functional :). TailWind CSS provides modern styling without bloat.
- **Projects Section**: Highlights key engineering and UX work.
- **Contact Info**: Includes where to reach me and my GitHub, social media platforms and research profiles.
