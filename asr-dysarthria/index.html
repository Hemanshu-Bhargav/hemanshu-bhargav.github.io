PAVOCAT: AI-Supported Captioning Study

Designing for trust and workload in AI-assisted live captioning systems using mixed methods research.

Problem Methods Findings Recommendations Impact Publication

Problem

Captioners using real-time speech recognition tools often experience high cognitive load and diminishing trust in AI systems.

Methods

Mixed-methods study with 21 captioners using NASA-TLX, SUS, and Trust in Automation metrics, supported by interviews.

Findings

  • Trust in AI declined over time
  • Mental workload reduced for novices
  • Desire for fine-grained control

Recommendations

  • Adjustable automation
  • Transparency indicators
  • Manual override options

Impact

Contributed to the HASO theory and proposed adaptive models for trust-calibrated interaction in AI-assisted tools.

Publication

Full thesis document with extended methodology, data, and analysis.
